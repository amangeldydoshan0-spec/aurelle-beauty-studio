# AURELLE Beauty Studio

Премиальный демонстрационный сайт салона красоты для портфолио.

## Стек

- React + Vite + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Запуск

```bash
cd beauty-salon
npm install
npm run dev
```

Сайт откроется на [http://localhost:5174](http://localhost:5174).

## Сборка

```bash
npm run build
npm run preview
```

## О проекте

Вымышленный салон **AURELLE Beauty Studio**. Форма записи работает в демо-режиме и не отправляет данные на сервер.
